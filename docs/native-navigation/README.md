# Native-feeling phone navigation (2026-11-04)

Synthetic filmstrips from WebKit with an iPhone user agent in Home Screen mode (390 × 844, motion on): the finger at
20%, 50% and 80% of the width, 70 ms after release, and at rest. Behind the moving screen is what Back restores.

| Journey | Filmstrip |
|---|---|
| Router provider detail → Providers (kept screen), Light | [light-router-detail.png](light-router-detail.png) |
| Same, Dark | [dark-router-detail.png](dark-router-detail.png) |
| Router → chat (the real chat underneath), Light | [light-router-to-chat.png](light-router-to-chat.png) |
| Library → chat, Dark | [dark-library-to-chat.png](dark-library-to-chat.png) |

Automated browsers drive synthetic touches; they do not replace a physical iPhone (Safari's own gestures, real touch
latency, ProMotion frame rates, VoiceOver).
