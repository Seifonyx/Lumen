## Architectural changes

**Index** keeps its compact persistent workspace index and creates a document-oriented reading plane: document title/metadata, brief, response and actual message actions. A selective intelligence margin replaces repetitive explanation blocks with an answer outline, real RouteWhy, selected route and context estimate. Outline buttons support keyboard activation and focus the actual rendered heading. Phone reading remains one column; the topbar's wordmark/context control exposes the existing intelligence dialog. The document heading sits outside the canonical ARIA feed, preserving article semantics.

**Studio** retains horizontal workspace navigation and gives the prompt a persistent full-height writing station beside independently scrolling response review. Expanded desktop writing reallocates the column widths. Phone writing mode uses the available main area, removes the unrelated navigation row while editing, keeps context/model/send controls reachable and returns to the conversation. There is one textarea, not a copied draft/editor with its own state.

**Shared composer** uses `ComposerChrome.tsx` for the presentation contract in both directions. The real Composer owns text, persistence, files, tool state and Send/Stop. Context controls invoke its existing file inputs/menu/events and settings. Research reflects the canonical chip and supports both enabling and disabling; absence of an enabled Gemini model disables the operation. Search follows the canonical manual-model capability behavior; Auto/Layouts retain existing send-time routing rules. Existing tool/project/repository chips and attachments remain available.

Expansion preserves the textarea DOM node, exact value, caret/selection direction, scroll position and editor focus. Escape collapses only from the editor when no active dialog owns the interaction; hidden/inert chat drawers do not block it. Scoped observation reads rendered canonical Research/file state, rather than introducing another tool store. Existing prefill events update the same writer and word count. A short writing-mode heading transition respects Reduce Motion; no spatial textarea animation disturbs selection.

The lower strip reuses the real ModelPicker and UsageMeter. The additional estimate combines canonical conversation context with the draft estimate; pending attachment payloads, complete system/tool overhead and provider billing are **not** included in that number. The canonical Usage dialog continues to describe conversation context separately. Unknown request allowance stays unknown. Numeric allowance comes only from canonical `remaining`; Auto/Layout label it as the **last model's** allowance, never a guaranteed quota for their next selection. Existing routing policies, model selection and fallback consent remain authoritative.

The wordmark is the brand anchor in desktop and phone navigation. Index and Studio use provisional optical/type treatments, consistent neutral surfaces, control geometry and functional hierarchy. No new symbol or approved brand decision is asserted. `workspace.css` is the only owner of these exploratory visual values; production `DESIGN.md`, `src/app.css` and runtime components were not changed.
