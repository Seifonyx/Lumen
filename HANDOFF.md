## Invariants and code pointers

- Account isolation: account-specific IndexedDB/drafts/cache. Legacy storage is claimed atomically once. Account changes reset state, abort jobs and use accountGeneration guards. Late callbacks must never write into the next account. See store.ts, lib/db.ts, lib/firebase.ts, lib/sync.ts and account-isolation/account-sync tests.
- Preserve offline drafts, attachments, project context, privacy masking/restoration and Ask-me review. Original attachment binaries do not sync; small text/metadata do. Do not send real user data or use keys in tests.
- Model catalogues are authoritative and free-only. Hide only confirmed disabled/retired models; 429/key/network errors remain inconclusive. Availability probes are explicit, context-free and bounded. Routing preserves manual choices, tools, provider-diverse fallbacks and bounded streams. See lib/ai/{providers,model-status,chat,health,http}.js and reliability/model-health/usage tests.
- Phone keyboard positioning: lib/viewport.ts follows visualViewport resize/scroll, defers offsets only during gestures and reconciles afterward. Keep --vv-h/touch.css behavior. These tests simulate iOS in Chromium, not physical Safari.
- Settings: Privacy & data merged; true black uses data-appearance=black with data-theme=dark. Sidebar gestures preserve native vertical scrolling and avoid inputs/selected text/code. Shared lib/focus-scope.ts owns nested dialog inert/focus; do not add competing inert effects. Local Escape handlers use data-local-escape.
- MessageThread windows histories above 120 messages, preserving focused/selected rows by ID. Full-conversation control and Ctrl/Cmd+F restore complete reading/search. Rendering must not truncate stored messages, AI context or exports.
- Coding: explicit review/apply/commit/PR actions. Plan approval binds device/account/repo/branch/context; individual edit decisions/base snapshots stay local and lock after commit. Undo supports the latest single-parent commit only, restores the exact parent tree with a new child commit and force:false, and guards uncommitted/racing/protected branches. See lib/{coding-plan,edit-review,commit-undo}.ts and matching tests.
- Knowledge (phase 11, deployed): Library → Knowledge; PDF/text/Markdown, local keyword search and Gemini Embedding 2 standard embedContent (768 dimensions; access metadata checked; no paid fallback). Explicit indexing masks detected details, reviews Ask-me findings, checkpoints each passage and pauses on quota/hidden/offline/account/key/privacy changes.
