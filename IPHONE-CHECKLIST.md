# iPhone check (about 10 minutes)

Use the app from the Home Screen (Safari → Share → Add to Home Screen) unless a step says Safari.
Use made-up text only, never patient details. Tick each box or note what went wrong.

## Start
- [ ] Open the app, sign in. The sidebar opens from ☰ and from a swipe at the left edge.
- [ ] Tap your avatar at the bottom: Settings opens. Back and ✕ work, nothing is cut off.
- [ ] Settings → API keys: providers list, search and the filter dropdown work; text stays inside cards.

## Chatting
- [ ] New chat shows the lime sparkles. Send "hi" on Auto: the line shows `Routing → model`.
- [ ] Turn on Web search (`+` menu) and ask about today's news: the line says "Searching the web".
- [ ] Tap the model name under that reply: "Why this model" opens and fits the screen; tap outside closes it.
- [ ] Rotate to landscape and back: message box and keyboard behave.

## Voice and images
- [ ] Mic button: dictate a sentence; the text lands in the box.
- [ ] Voice mode (waveform button): say something, hear the answer, tap to stop.
- [ ] `+` → Camera, then Photos: attach a picture, ask what's in it.
- [ ] Ask "make an image of a lime-green paper plane" (needs Cloudflare or Hugging Face connected).

## Files
- [ ] Attach a small Word file and ask to change one sentence: "Download edited file" saves a .docx that opens in Files/Word with formatting kept.
- [ ] Under a reply: `⋯` → Share opens the iPhone share sheet; Save as Word downloads.

## Chats
- [ ] Sidebar → Recents → Select: tick two chats, Export saves a .zip, Delete removes them.
- [ ] Share link (chat menu → Share or export → link): open it in Safari's private tab; it shows read-only.

## Tasks and notifications
- [ ] Library → Tasks → Turn on notifications: allow (on iPhone this only appears in the Home Screen app).
- [ ] Easier on a computer: make a reminder for 2 minutes from now, leave the app open and switch to
      another window. A notification arrives; clicking it opens the reminder's chat.
      (Tasks only run while the app is open, so a phone in your pocket won't run them.)

## Settings
- [ ] Models → Check models → Start: progress, then Done. Models → Review shows removed models with reasons.
- [ ] Appearance: Light, Dark and Black all look right, including the status bar area.
