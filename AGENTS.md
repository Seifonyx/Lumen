# Working on Lumen

Read [HANDOFF.md](HANDOFF.md) when starting or resuming work, then follow the user's current request.

Update HANDOFF.md as part of the work, without waiting to be asked: after meaningful progress, before committing,
and before pausing or handing off. Include the current goal and branch, what changed, checks and their results,
unfinished work or blockers, and the next concrete action. Make partial or unverified work clear.

Keep one concise, current checkpoint. Replace stale status; completed history belongs in git. Use the code and
configuration for implementation details, and [README.md](README.md) for setup.
