Try these checks

  1. Switch between Workspace and Routing Center, type a distinctive draft, open context/usage, and return. The draft should remain.
  2. Pick a manual model, switch back to Auto, then choose Launch writing. Inspect its route from the composer.
  3. In Routing Center → Policies & fallbacks, edit Launch writing, move a model, change fallback permissions, save, and reopen. The chosen order and permission should persist locally.
  4. Open provider management and inspect Gemini. The key stays masked. Unknown quota stays unknown.
  5. Compare the exact same state with the baseline, then inspect the full-resolution phone image. Linux WebKit is a compatibility check, not a physical iPhone.

The manual preview is explicitly local and synthetic. It blocks external provider calls. Its Send path reports preview unavailability; Stop was separately exercised with an intercepted request by the automated harness.
